通过 Zeabur Installer 的网页界面完成五个步骤，就能打开 Zeabur 并注册首位管理员的通行密钥。点击“安装”之前，installer 不会改动服务器。

以下安装流程适合团队使用。如果仅供自己使用，或机器内存不足 4 GiB，参见[个人使用：在小型机器上安装](personal.mdx)。

## 准备服务器

准备一台满足以下条件的服务器：

- 使用 systemd 的 Linux，架构为 amd64 或 arm64。
- 具备 root 权限。
- 内存至少 4 GiB。
- `/var/lib/rancher` 至少有 10 GiB 可用空间。低于 30 GiB 时，installer 会显示提醒。
- TCP 端口 80、443、6443、9345、10250 未占用。
- 未安装 k3s、kubeadm、k0s 或 MicroK8s。

从 [GitHub Releases](https://github.com/zeabur-oss/zeabur/releases) 下载与服务器架构匹配的 `zeabur-installer-v<version>-linux-<arch>.tar.gz`。验证方法参见[发行文件与验证](../reference/releases.mdx)。

发行版 installer 固定了 RKE2、Zeabur Catalog、Zeabur Identity 和 Zeabur 的版本。安装所需的文件会下载到 `/var/lib/rancher/zeabur-installer/downloads`，并校验 SHA-256。

## 打开安装界面

在服务器上运行：

```sh
sudo zeabur-installer gui
```

installer 默认只监听 `127.0.0.1:8085`，终端会输出带有令牌的链接，例如：

```text
http://127.0.0.1:8085/?token=…
```

在自己的电脑上打开另一个终端，建立 SSH 隧道：

```sh
ssh -L 8085:127.0.0.1:8085 root@<服务器>
```

然后在自己电脑的浏览器中打开刚才带有令牌的链接。

界面右上角可以切换语言和主题。页面上方依次是“服务器”“连接方式”“组件”“确认”“安装”五个步骤。点击“继续”进入下一步，点击“上一步”返回修改。

## 1. 检查服务器

在“检查服务器”中确认主机名、架构、内存和地址，再处理未通过的检查项。在“供谁使用”中选择“团队使用”。内存不足 4 GiB 时只能选择“个人使用”，参见[个人使用：在小型机器上安装](personal.mdx)。

![“检查服务器”显示主机信息与检查结果](https://oss.zeabur.com/shots/zeabur/zh-CN/light/installer-host.avif)

检查项包括管理员权限、systemd、时钟、Swap、为崩溃转储预留的内存、其他 Kubernetes、端口、磁盘空间和磁盘加密。先修正未通过的检查项，再点击“重新检查”。

出现警告时仍可继续。例如，磁盘未加密时会出现警告。Secret 会加密，卷不会，测试机可以继续安装。

页脚会说明所选配置保存到 `/etc/zeabur-installer/config.yaml`。

## 2. 选择连接方式

在“大家如何连接到 Zeabur”中配置两个不同的域名：

- “Zeabur”：大家访问 Zeabur 的地址，例如 `zeabur.example.com`。
- “登录”：Zeabur Identity 的地址，例如 `login.example.com`。大家会在这里使用通行密钥登录。

![“大家如何连接到 Zeabur”的证书与域名配置](https://oss.zeabur.com/shots/zeabur/zh-CN/light/installer-access.avif)

在“证书”中选择“公开域名”或“测试机”。

页面下方的“应用域名”决定新服务的建议地址。可以暂时留空，之后为每个服务填写完整域名，也可以到**集群**页面配置。

### 公开域名

使用自己的域名时，选择“公开域名”。两个域名都需要有指向这台服务器的 DNS 记录，且互联网必须能访问服务器的 TCP 80 和 443 端口。

证书由 Let's Encrypt 签发。字段下方会显示域名是否指向这台服务器。

### 测试机

测试时，选择“测试机”，再点击“使用 sslip.io 域名”，填入：

- `zeabur.<地址>.sslip.io`
- `login.<地址>.sslip.io`

这样无需配置 DNS。证书由在服务器上创建的证书颁发机构签发，安装完成后需要将证书导入浏览器或系统，并设为受信任。

## 3. 选择组件

在“选择组件”中先选择“预设组合”，再根据需要勾选或取消勾选各个组件。

![“选择组件”的预设组合、组件列表与内存估算](https://oss.zeabur.com/shots/zeabur/zh-CN/light/installer-components.avif)

| 预设组合 | 内容 |
| --- | --- |
| “精简” | Ingress、证书和 metrics-server |
| “标准” | 组件目录建议在单台服务器上安装的全部组件，这是默认选项 |
| “增强” | 在“标准”基础上增加运行时威胁检测、漏洞扫描和入侵防护 |

其他组件所依赖的组件会一并加入，并标注“其他组件需要”。标注“特权”的组件会以主机权限运行。

上方会显示已选数量和空闲状态下的内存估算，结果分为“够用”“快不够了”“不够用”。根据估算调整选择，再点击“继续”。

## 4. 确认并开始安装

在“确认”中核对地址、组件和内存估算，确认后点击“安装”。

![“确认”显示安装摘要、警告与详细信息](https://oss.zeabur.com/shots/zeabur/zh-CN/light/installer-review.avif)

摘要会列出：

- 空闲时的内存用量。
- 选定的组件。
- Kubernetes 版本，即 RKE2 版本。
- 连接方式和地址。
- 所需时间，约 10 到 20 分钟。

先阅读“安装前请注意”中的警告。例如，测试机的域名也必须通过 DNS 解析到这台服务器。只修改 hosts 文件不够，Pod 不会读取它。

展开“详细信息”可以查看 Chart 及其版本、配置文件和完整计划。点击“下载”可保存 `config.yaml`。

如果有检查项未通过，或内存估算为“不够用”，“安装”按钮将不可用。修正问题或调整组件后再开始。

## 5. 查看安装进度

“正在安装”会显示时间轴，整个过程约需 10 到 20 分钟。点击“显示日志”可以查看完整输出。

![“正在安装”显示安装时间轴与进度](https://oss.zeabur.com/shots/zeabur/zh-CN/light/installer-install.avif)

时间轴依次列出包检查服务器、安装 Kubernetes（RKE2）、Namespace 和连接规则、存储空间、各组件、证书颁发机构、Zeabur Identity、Zeabur 和收尾。证书颁发机构只会在测试机模式下安装。

关闭页面不会中断安装。重新打开带有令牌的链接，就能继续查看进度。

## 注册首位管理员

看到“Zeabur 已就绪”后，在“首位管理员”中点击“注册通行密钥”。完成注册后，点击“打开 Zeabur”登录。

这个账号是管理员账号，只能使用通行密钥登录，拥有整个集群的完整权限。日常部署、查看日志等工作，可以到**成员**中为自己邀请一个普通账号来完成，参见[管理员账号和普通账号](../reference/permissions.mdx#管理员账号和普通账号)。

![“Zeabur 已就绪”显示首位管理员的注册入口](https://oss.zeabur.com/shots/zeabur/zh-CN/light/installer-done.avif)

<Callout type="warn">
首位管理员的注册链接会创建管理员账号，谁先打开，谁就能完全控制集群。只将链接交给负责管理集群的人。链接只能使用一次，有效期为 24 小时。
</Callout>

测试机模式下，要先点击“下载证书”，将证书导入浏览器或系统并设为受信任，否则浏览器会显示警告。证书文件也保存在服务器的以下路径：

```text
/var/lib/rancher/zeabur-installer/local-ca.crt
```

注册链接过期时，在服务器上运行以下命令，生成新链接：

```sh
zeabur-identityctl setup-link --username admin
```

完成后，在服务器终端中按 Ctrl-C 结束 installer。RKE2 和服务会继续运行。

## 安装已停止时

看到“安装已停止”时，先查看页面指出的步骤，再阅读日志最后几行中的错误原因。可能的原因包括内存不足、服务器检查未通过或超时。

![“安装已停止”显示停止的步骤与错误信息](https://oss.zeabur.com/shots/zeabur/zh-CN/light/installer-failed.avif)

修正后点击“重新安装”。installer 会从头开始，跳过已就绪的部分，不会移除任何内容。

## 检查安装结果

在服务器上运行：

```sh
sudo zeabur-installer doctor
```

这会检查 RKE2、组件、默认存储类、Zeabur Identity 和 Zeabur。

| 退出码 | 结果 |
| --- | --- |
| `0` | 正常 |
| `1` | 警告 |
| `2` | 严重 |
| `3` | 无法运行检查，例如未使用 root 运行 |

接下来可以[部署第一个服务](first-project.mdx)。

## 改用配置文件和命令

要重复安装、将配置纳入版本控制，或无法建立 SSH 隧道时，参见[使用配置文件和命令安装](advanced-install.mdx)。网页界面写入的配置文件，就是命令行读取的同一份文件。

## 移除 Zeabur

只移除 Zeabur 时，在服务器上运行：

```sh
sudo zeabur-installer uninstall zeabur
```

RKE2、组件、Zeabur Identity 和应用会保留。其他移除方式参见[移除 Zeabur，保留服务](../leave/uninstall.mdx)。
